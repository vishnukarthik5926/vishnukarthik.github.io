CAMOS Satellite Simulator

A comprehensive dual-MCU simulation system for spacecraft operations. Built with STM32 as the main flight computer and ESP32 modules for satellite and ground station simulation. Features fault detection, isolation, and recovery (FDIR) logic, OLED telemetry display, and real-time serial communication between boards.

STM32 ESP32 C MicroPython MQTT I2C
In Progress

What I Learned:

Multi-board communication, UART/I2C protocols, FDIR design patterns, and the complexity of real-time embedded systems.

Python JavaScript HTML/CSS WebSocket STT/TTS
In Progress

What I Learned:

Speech recognition integration, real-time websocket communication, modular architecture design, and creating immersive UI experiences.

An ESP32-based sensor network with a real-time web dashboard for home monitoring. Collects temperature, humidity, and motion data from multiple nodes. Features device control capabilities and data logging for historical analysis.

Completed

Completed

What I Learned:
